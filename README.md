## Этап 4. Основные команды

На четвёртом этапе реализована работа основных команд UNIX-подобной оболочки с виртуальной файловой системой (VFS).

### Реализованные команды

| Команда | Описание |
|---|---|
| `ls [путь]` | Вывод содержимого каталога |
| `ls -a [путь]` | Вывод содержимого, включая скрытые элементы |
| `cd [путь]` | Изменение текущего каталога |
| `cd ..` | Переход в родительский каталог |
| `tail файл` | Вывод последних 10 строк текстового файла |
| `tail -n N файл` | Вывод последних N строк |
| `uptime` | Время работы эмулятора |
| `exit` | Завершение работы |

### Особенности реализации

- Поддерживаются абсолютные и относительные пути.
- Поддерживаются имена файлов и каталогов с пробелами при использовании кавычек.
- Команды работают с виртуальной файловой системой, загруженной из JSON.
- Исходный JSON-файл не изменяется.
- Ошибки выполнения команд обрабатываются без аварийного завершения графического интерфейса.
- Стартовый сценарий прекращает выполнение при первой ошибке.
- `uptime` показывает время текущего сеанса эмулятора, а не время работы настоящей операционной системы.

### Запуск

Запуск с тестовой VFS:

```powershell
py src/main.py --vfs scripts/vfs_stage4.json
```

Запуск успешного сценария:

```powershell
.\scripts\run_stage4_ok.bat
```

Запуск сценария с ошибкой:

```powershell
.\scripts\run_stage4_error.bat
```

### Автоматическое тестирование

```powershell
py -m unittest discover -s tests -p "test_stage4.py" -v
```

### Ограничения

Эмулятор реализует учебный набор возможностей команд, а не полную функциональность UNIX. Команды работают с текстовыми файлами VFS. Поддержка дополнительных ключей и двоичных данных в основных командах не реализована.


## Этап 5. Операции с виртуальной файловой системой

На пятом этапе реализованы команды создания и удаления элементов виртуальной файловой системы.

### Реализованные команды

| Команда | Описание |
|---|---|
| `mkdir путь` | Создание каталога |
| `mkdir -p путь` | Рекурсивное создание вложенных каталогов |
| `rm файл` | Удаление файла |
| `rm -r каталог` | Рекурсивное удаление каталога |
| `rm -f файл` | Удаление без ошибки при отсутствии файла |
| `rm -rf путь` | Рекурсивное принудительное удаление |

### Особенности реализации

- Команды работают с виртуальной файловой системой в памяти Python.
- Исходный JSON-файл не изменяется.
- Поддерживаются абсолютные и относительные пути.
- Созданные каталоги доступны командам `ls` и `cd`.
- Удалённые элементы перестают отображаться в `ls`.
- Предусмотрена обработка неправильных аргументов и несуществующих путей.
- Запрещено удаление корневого и текущего каталогов, а также предков текущего каталога.
- Стартовые сценарии останавливаются при первой ошибке.

### Запуск эмулятора

```powershell
py src/main.py --vfs scripts/vfs_stage5.json
```

### Успешный сценарий

```powershell
.\scripts\run_stage5_ok.bat
```

### Сценарий с ошибкой

```powershell
.\scripts\run_stage5_error.bat
```

### Проверка неизменности JSON

```powershell
Get-FileHash .\scripts\vfs_stage5.json -Algorithm SHA256
```

### Ограничения

Реализован учебный набор параметров команд `mkdir` и `rm`. Операции не затрагивают реальную файловую систему и не сохраняются между запусками эмулятора.
