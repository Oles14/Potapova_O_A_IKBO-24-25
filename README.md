# Эмулятор командной оболочки ОС

**Практическая работа по конфигурационному управлению**  
**Вариант № 19**  
**Этап 2. Конфигурация**

## Цель работы

Добавить возможность настройки эмулятора через параметры командной строки и реализовать автоматическое выполнение команд из стартового сценария.

## Реализованная функциональность

Сохранены возможности первого этапа:

- Графический интерфейс Tkinter.
- Интерактивный ввод команд.
- Парсер `shlex.split()` с поддержкой кавычек.
- Команды-заглушки `ls`, `cd`.
- Команда `exit`.
- Обработка неизвестных команд и ошибок разбора.

Дополнительно реализованы:

- Обработка параметров запуска через `argparse`.
- Отладочный вывод заданных параметров.
- Загрузка стартового сценария из текстового файла.
- Последовательное выполнение команд сценария.
- Отображение введённых команд и результатов выполнения.
- Остановка стартового сценария при первой ошибке.
- Сообщения об ошибках открытия сценария.

## Параметры командной строки

| Параметр | Назначение |
|---|---|
| `--vfs` | Путь к физическому расположению VFS |
| `--script` | Путь к стартовому сценарию |

На втором этапе путь VFS принимается и отображается в отладочной информации. Загрузка и обработка содержимого VFS будут реализованы на третьем этапе.

## Запуск

Запуск без параметров:

```powershell
py src/main.py
```

Запуск с указанием пути VFS:

```powershell
py src/main.py --vfs my-vfs.json
```

Запуск с успешным сценарием:

```powershell
py src/main.py --vfs my-vfs.json --script scripts/stage2_ok.txt
```

Запуск со сценарием, содержащим ошибку:

```powershell
py src/main.py --vfs my-vfs.json --script scripts/stage2_err.txt
```

Также предусмотрены BAT-файлы для запуска в Windows.

## Стартовые сценарии

### stage2_ok.txt

Проверяет последовательное выполнение корректных команд, включая аргументы с пробелами в кавычках.

### stage2_err.txt

Содержит неизвестную команду `abracadabra`, после которой выполнение сценария прекращается.

## Обработка ошибок

Реализована обработка:

- Неизвестных команд.
- Ошибок разбора кавычек.
- Отсутствующего или недоступного файла сценария.
- Ошибок во время выполнения сценария.

## Результат

Эмулятор поддерживает настройку параметров запуска, отображает отладочную информацию и автоматически выполняет команды из стартового сценария с остановкой при первой ошибке.
