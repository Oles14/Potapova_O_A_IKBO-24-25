# Эмулятор командной оболочки ОС

**Практическая работа по конфигурационному управлению**  
**Вариант № 19**  
**Этап 1. REPL**

## Цель работы

Разработать минимальный прототип эмулятора UNIX-подобной командной оболочки с графическим интерфейсом и возможностью интерактивного ввода команд.

## Реализованная функциональность

- Графический интерфейс на Python с использованием библиотеки Tkinter.
- Окно с заголовком, содержащим имя виртуальной файловой системы `my-vfs`.
- Поле для ввода команд и область отображения результатов.
- Обработка команд после нажатия Enter.
- Разбор команд и аргументов с помощью `shlex.split()`.
- Поддержка аргументов в кавычках, в том числе содержащих пробелы.
- Обработка ошибок разбора и неизвестных команд.
- Команда завершения работы `exit`.

## Поддерживаемые команды

| Команда | Назначение |
|---|---|
| `ls` | Заглушка, выводящая имя команды и аргументы |
| `cd` | Заглушка, выводящая имя команды и аргументы |
| `exit` | Завершение работы эмулятора |

На первом этапе команды `ls` и `cd` не выполняют реальных операций с файловой системой.

## Запуск

Из корневой папки проекта:

```powershell
py src/main.py
```

После запуска откроется графическое окно эмулятора.

## Примеры команд

```text
ls
cd documents
ls "my file.txt"
cd "my folder"
unknown
exit
```

Программа выводит название и аргументы команд-заглушек, сообщает об ошибках и завершает работу по команде `exit`.

## Обработка ошибок

Предусмотрена обработка:

- Неизвестных команд.
- Неправильно закрытых кавычек.
- Ошибок разбора пользовательского ввода.

## Результат

Создан работающий прототип графического эмулятора командной оболочки с интерактивным вводом, разбором аргументов и базовыми командами-заглушками.
