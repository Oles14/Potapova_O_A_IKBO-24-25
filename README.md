# Эмулятор командной оболочки ОС

**Практическая работа по конфигурационному управлению**  
**Вариант № 19**  
**Этап 4. Основные команды**

## Цель работы

Реализовать основные команды UNIX-подобной оболочки для работы с виртуальной файловой системой.

## Реализованная функциональность

Сохранены возможности предыдущих этапов:

- Графический интерфейс Tkinter.
- Парсер с поддержкой кавычек.
- Параметры `--vfs` и `--script`.
- Выполнение стартовых сценариев.
- Загрузка VFS из JSON.
- Обработка ошибок.
- Работа с VFS в оперативной памяти.

Добавлены полноценные команды `ls`, `cd`, `tail`, `uptime`.

## Поддерживаемые команды

| Команда | Назначение |
|---|---|
| `ls` | Вывод содержимого текущего каталога |
| `ls путь` | Вывод содержимого указанного каталога |
| `ls -a` | Вывод с включением скрытых элементов |
| `cd путь` | Переход в каталог |
| `cd ..` | Переход в родительский каталог |
| `cd /` | Переход в корень VFS |
| `tail файл` | Вывод последних 10 строк файла |
| `tail -n N файл` | Вывод последних N строк |
| `uptime` | Время работы эмулятора |
| `exit` | Завершение работы |

## Особенности реализации

- Поддерживаются абсолютные и относительные пути.
- Поддерживаются `.` и `..` при обработке путей.
- Имена с пробелами можно указывать в кавычках.
- Команды работают с виртуальными файлами и каталогами.
- `tail` читает текстовое содержимое файлов VFS.
- `uptime` показывает время работы текущего сеанса эмулятора, а не реальной ОС.
- Исходный JSON-файл не изменяется.

## Запуск

Интерактивный режим:

```powershell
py src/main.py --vfs scripts/vfs_stage4.json
```

Успешный стартовый сценарий:

```powershell
.\scripts\run_stage4_ok.bat
```

Сценарий с ошибкой:

```powershell
.\scripts\run_stage4_error.bat
```

## Примеры команд

```text
ls
ls -a
ls /home
cd /home/student
cd documents
ls
tail notes.txt
tail -n 3 notes.txt
cd ..
cd /
uptime
exit
```

## Автоматическое тестирование

Для проверки используется стандартная библиотека Python `unittest`.

Запуск:

```powershell
py -m unittest discover -s tests -v
```

В файле `tests/test_stage4.py` реализовано 14 тестов, проверяющих:

- Работу `ls` и `ls -a`.
- Абсолютные и относительные пути.
- Переход в родительский каталог.
- Ошибки перехода.
- Работу `tail`.
- Некорректные аргументы `tail`.
- Команду `uptime`.
- Неизвестные команды.
- Неизменность исходного JSON.

## Обработка ошибок

Реализованы сообщения при:

- Отсутствии файла или каталога.
- Попытке перейти в файл.
- Некорректных аргументах.
- Неправильном количестве строк для `tail`.
- Неизвестных командах.

При ошибке стартовый сценарий прекращает выполнение.

## Ограничения

Эмулятор реализует учебный набор возможностей UNIX-подобных команд. Не все параметры настоящих UNIX-утилит поддерживаются.

## Результат

Реализованы основные команды работы с виртуальной файловой системой, поддержка путей и обработка ошибок. Для проверки предусмотрены стартовые сценарии и автоматические тесты.
