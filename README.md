# Эмулятор командной оболочки ОС

**Практическая работа по конфигурационному управлению**  
**Вариант № 19**  
**Этап 3. Виртуальная файловая система (VFS)**

## Цель работы

Реализовать загрузку виртуальной файловой системы из JSON-файла и обеспечить выполнение операций с её структурой в оперативной памяти.

## Реализованная функциональность

Сохранены возможности предыдущих этапов:

- Графический интерфейс Tkinter.
- Интерактивный ввод команд.
- Парсер с поддержкой аргументов в кавычках.
- Параметры запуска `--vfs` и `--script`.
- Выполнение стартовых сценариев.
- Остановка сценария при первой ошибке.

Дополнительно реализованы:

- Загрузка VFS из JSON-файла.
- Представление файлов и каталогов в виде древовидной структуры.
- Проверка корректности формата VFS.
- Обработка ошибок загрузки.
- Отображение имени VFS в заголовке окна.
- Подсчёт количества файлов и каталогов.
- Определение максимальной глубины файловой системы.
- Работа с VFS без изменения исходного JSON-файла.

На данном этапе `ls` и `cd` остаются командами-заглушками. Полноценная работа с каталогами будет добавлена на четвёртом этапе.

## Формат VFS

Виртуальная файловая система описывается JSON-объектом.

Пример:

```json
{
  "name": "example-vfs",
  "type": "dir",
  "children": {
    "documents": {
      "type": "dir",
      "children": {
        "notes.txt": {
          "type": "file",
          "content": "Hello, world!"
        }
      }
    }
  }
}
```

Основные поля:

- `name` — имя VFS.
- `type` — тип элемента (`dir` или `file`).
- `children` — содержимое каталога.
- `content` — текстовое содержимое файла.

Текущая реализация рассчитана на текстовое содержимое файлов. Отдельная обработка двоичных данных через base64 не реализована.

## Запуск

Минимальная VFS:

```powershell
py src/main.py --vfs scripts/vfs_min.json
```

VFS с несколькими файлами:

```powershell
py src/main.py --vfs scripts/vfs_multi.json
```

VFS с глубокой вложенностью:

```powershell
py src/main.py --vfs scripts/vfs_deep.json
```

Некорректная VFS:

```powershell
py src/main.py --vfs scripts/vfs_bad.json
```

Несуществующий файл VFS:

```powershell
py src/main.py --vfs scripts/missing.json
```

Запуск со стартовым сценарием:

```powershell
py src/main.py --vfs scripts/vfs_multi.json --script scripts/stage3_ok.txt
```

|---|---|
| `vfs_min.json` | Минимальная файловая система |
| `vfs_multi.json` | Несколько файлов и каталогов |
| `vfs_deep.json` | Вложенность более трёх уровней |
| `vfs_bad.json` | Проверка некорректного формата |

## Обработка ошибок

Предусмотрены сообщения при:

- Отсутствии JSON-файла.
- Некорректном JSON.
- Неправильной структуре VFS.
- Ошибках загрузки стартового сценария.
- Неизвестных командах и ошибках разбора ввода.

При невозможности загрузить VFS выполнение команд блокируется.
