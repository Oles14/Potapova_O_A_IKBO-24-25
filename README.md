# Эмулятор командной оболочки ОС

**Конфигурационное управление | Вариант № 19**  
**Этап 1. REPL**

## Цель работы

Создать прототип UNIX-подобной командной оболочки с графическим интерфейсом и интерактивным вводом команд.

## Реализованная функциональность

- GUI на Python с использованием Tkinter.
- Имя VFS (`my-vfs`) в заголовке окна.
- Ввод команд и отображение результатов.
- Разбор аргументов в кавычках с помощью `shlex.split()`.
- Обработка неизвестных команд и ошибок ввода.

**Поддерживаемые команды:**

| Команда | Описание |
|---|---|
| `ls` | Заглушка, выводящая имя и аргументы |
| `cd` | Заглушка, выводящая имя и аргументы |
| `exit` | Завершение работы |

## Запуск

Из корневой папки проекта:

```powershell
py src/main.py
```

## Примеры работы

```text
ls
cd documents
ls "file with spaces.txt"
unknown
exit
```

Команды `ls` и `cd` на данном этапе являются заглушками. При неизвестной команде или ошибке разбора выводится соответствующее сообщение.

## Результат

Реализован графический прототип эмулятора с интерактивным вводом, разбором аргументов и базовой обработкой ошибок.
